# Instruções para esta branch

Leia [REGRAS.MD](REGRAS.MD) e [README.md](README.md) antes de editar. Esta branch contém uma demonstração em React com dados locais. A documentação acadêmica em `docs-entrega/` registra a versão original.

Preserve o login de demonstração, o projeto teste, as três regras simuladas e a auditoria por aba. Não introduza backend, arquivos de ambiente, serviços externos ou execução do código apresentado nos exemplos.

Valide alterações a partir da raiz:

```bash
npm ci
npm run build
npm run test -- --run
```
